XI TKJ 1 — FRONTEND GITHUB PAGES

1. Upload isi folder ini ke repository GitHub.
2. Pastikan index.html ada di root repository.
3. Settings → Pages → Deploy from branch → main → /root.
4. Sebelum/ sesudah backend Render jadi, edit config.js:
   window.KYOU_CONFIG = { API_BASE: "https://URL-BACKEND-RENDER" };

Jadwal dan piket pada script.js dipertahankan.
